# 常见问题

**Q：它会把我的代码/对话发到哪里去吗？**
A：不。全部在本机 SQLite 文件里（`<项目>/.sessionrelay/relay.sqlite`）。没有网络调用，没有 embedding 服务。
默认的语义档也是**本地 CPU 推理**，且默认关闭。

**Q：能跨项目查吗？**
A：不能，这是**有意**的。一个项目一个库，删目录 = 彻底消失。
多项目"互相看见"通常意味着你在任何项目里都能翻到另一个项目的秘密。

**Q：为什么不用向量数据库 / embedding？**
A：取舍问题。我们买的是零成本、离线、~5ms、每条结论带出处可回跳原文。
代价是**换词命中弱**——这条写在 README 里，不藏。

**Q：DSH 那边要装什么？**
A：内核（一次）+ DSH 插件（`packages/dsh-plugin`，丢进 profile 的 `local-plugins/`）+ **重启 DSH**。
插件需要 vendor（约 61MB），走 Release 离线包最省事。

**Q：装完为什么看不到简报？**
A：按 [INSTALL.md](INSTALL.md) §C 的七条验收逐条走。最常见两个原因：
① 项目还没 `srelay init`（没有库 → 没内容可注入）；② 常驻进程没重启。

**Q：简报里的内容是真读库还是写死的？**
A：DSH 侧是**每个模型步骤前现查一次**（所以你这一轮的决定下一轮就在）；
ZCode 侧是 SessionStart 查一次。两者共用同一套过滤规则。

**Q：怎么彻底卸载？**
A：删 `.sessionrelay/` 目录（记忆）、移除适配器目录、卸载全局 CLI。
ZCode 侧安装时留了 `config.json.bak-*`，可精确恢复。
